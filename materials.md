## Shell (Command Line Interfaces) and Git

### Handouts

[Command Line Interfaces: an introduction to Unix and Bash](./docs/shell-handout.html)  
[Version control with Git](./docs/git-handout.html)

These are reference documents. In class, we will discuss some parts of them, and
you can read them deeper on your own and come back later at any time when you
need something from there. 

### Exercises

[Shell and Git](https://classroom50.org/bse-computing-brushup/iicds-2026/assignments/shell-git/accept)

One assignment containing a short guide to working with git in a repository, a data pipeline exercise in shell, and an optional command-line detective game. None of it is graded, but the pipeline exercise is worth attempting — see the README in the repository for what to do first.

_Recommended literature:_ "Classic Shell Scripting" by Arnold Robbins and Nelson H. F. Beebe; [Data Science at the Command Line](https://datascienceatthecommandline.com/) by Jeroen Janssens (free online).
